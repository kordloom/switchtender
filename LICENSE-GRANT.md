# Supplemental license grant

KordLoom LLC, the licensor of SwitchTender, makes this grant on 2026-09-22.

## What this grants

Every version of SwitchTender published before v1.72.0 shipped a `LICENSE` file whose Change Date
reads `2030-07-07`, a fixed date. Versions from v1.72.0 onward read `Two years after the date each
version of the Licensed Work is first publicly released`.

For every version published before v1.72.0, the Change Date is two years after the date that version
was first publicly released. That date replaces the `2030-07-07` printed in those versions' `LICENSE`
files, and on it each of those versions converts to the Apache License, Version 2.0, exactly as the
later versions do.

This grant is irrevocable.

## Why it exists

The Business Source License applies separately to each version, and the Change Date may differ
between them, so the wording in the current `LICENSE` governs only the versions that carry it. The
two-year conversion was published as a commitment before the `LICENSE` file said it, and 95 of the
versions released under that commitment carry the older fixed date instead. This grant makes the
text match the commitment rather than narrowing the commitment to match the text.

It only adds. Nothing here takes away a right anyone already holds, and no version converts later
than its own `LICENSE` file already says.

## Scope

This changes one parameter of the Business Source License for the versions named above. Everything
else about them is unchanged, including the Additional Use Grant and the Change License. Versions
from v1.72.0 onward are unaffected, since their own `LICENSE` already states the two-year date.

The set of versions this covers is closed. It cannot grow, because every version released after
v1.72.0 carries the correct Change Date in its own `LICENSE`.

## Where this is published

This file sits beside `LICENSE` in the public repository at
https://github.com/kordloom/switchtender, is referenced from the licensing terms at
https://switchtender.com/terms, and is attached to releases from the date above so an artifact
carries it rather than pointing at a repository to find it.
