Install and import it Have it done with you

Your export is never sent anywhere, and you can check that rather than take it on trust: open your browser's network panel, drop the file, and watch nothing leave once the page has loaded. The reader is a WebAssembly build of the same code the switchtender assess command runs, so the file is opened by your own browser and the report is produced on your machine. An export names every project, inventory, credential and schedule you run, which is the map of your estate, and handing that to a stranger to get a sales document back is a bad trade. Run switchtender assess awx export.json yourself and you get this same report from a terminal.

Where to get an export. From AWX or Ansible Automation Platform, awx export --all > export.json with the AWX CLI, or the Tower CLI equivalent. The same file is what switchtender import awx reads, so an export that assesses here is one that imports.

What the grades mean. Every count comes from the graders the product uses when it actually runs something, not from a separate heuristic written for this page, so a number here cannot disagree with what a run later says. Grades are read from what each template declares: its tool, command, limit, and variables. A template whose playbook text lives in a repository nothing has fetched yet is graded from its declaration alone, and reading that playbook can only raise a grade, never lower one, so the numbers are a floor. Reversibility and risk are defined in the concepts.
