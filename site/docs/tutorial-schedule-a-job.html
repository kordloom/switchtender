Schedule a job

A schedule uses a cron expression, and it can fire a stored template, a single run, a split, or a whole pipeline.

Schedule a template

  1. Save the work first as a template, so the schedule stays a one-line reference instead of a copy of every field.
  2. Open Schedules and add a schedule.
  3. Give it a cron expression for the cadence, for example 0 2 * * * for 02:00 every day, and point it at the template.
  4. Save. It fires on the schedule and each firing shows up in Runs like any other.

From the API

curl -s -X POST localhost:8080/v1/schedules \
  -H 'content-type: application/json' \
  -d '{"cron":"0 2 * * *","template_id":"tpl_abc123"}'

To schedule without a template, send playbook and inventory inline, add shards for a split, or steps for a pipeline. A worker or the server must be running for a schedule to fire. Add capacity with switchtender worker.
